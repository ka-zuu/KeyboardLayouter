# 用語集

自作キーボードの用語と、本アプリのコード上の名前の対応です。
コード内の識別子は英語、ドキュメントの説明は日本語で書きます。

## 寸法・座標

| 用語 | コード上の名前 | 説明 |
|---|---|---|
| U (ユニット) | `U`, `xU`, `MM_PER_U` | キー 1 個分の大きさを 1 とする単位。1U = 19.05mm (Cherry MX の標準ピッチ)。「1.5U キー」は横幅が 1.5 倍のキー |
| ピッチ | – | 隣り合うキーの中心間距離。標準は 19.05mm |
| レイアウト座標 | `PointU`, `xU` | モデルが持つ U 単位の座標。Y は下方向が正 |
| 物理座標 | `xMm` | mm 単位。KiCad 出力で使う |
| 画面座標 | `xPx` | 画面ピクセル。`scale` と `panPx` で変換 |
| スナップ | `snapU`, `gridSize` | 座標をグリッドの倍数に吸着させること |
| AABB | `getRotatedRectAABB` | Axis-Aligned Bounding Box。軸に平行な最小の囲み矩形 |
| SAT | `doPolygonsIntersect` | Separating Axis Theorem (分離軸定理)。凸多角形同士の交差判定に使う |

## キーとキーキャップ

| 用語 | コード上の名前 | 説明 |
|---|---|---|
| キーキャップ | – | 指が触れる樹脂部品。本アプリが描いているのはこれ |
| スイッチ | `SW` (回路図の Reference) | キーキャップの下にある機構部品。1 キーに 1 個 |
| 刻印 (レジェンド) | `legends`, `LegendSlot` | キーキャップに印字された文字。本アプリでは 12 スロット |
| 前面刻印 | `frontLeft` / `frontCenter` / `frontRight` | キーキャップの手前側面に入る刻印 |
| ISO Enter | `shape: 'isoEnter'` | 欧州配列の L 字型 Enter キー |
| Big-Ass Enter | `shape: 'bigAssEnter'` | 逆 L 字型の大きな Enter キー |
| ステップド | `shape: 'steppedCaps'` | 段差のあるキーキャップ (Caps Lock で使われる)。KLE では `l: true` |
| デカール | `decal` | スイッチを持たない装飾専用の要素。KLE では `d: true`。出力から除外する |
| ホーミング | `homing` | 指の位置を示す突起やくぼみのあるキー (F, J など)。KLE では `n: true` |
| ゴースト | `ghost` | 「そこにキーがない」ことを示す半透明表示。KLE では `g: true` |
| 副矩形 | `secondary`, `x2`/`y2`/`w2`/`h2` | 矩形 1 つで表せない形状を表すための 2 つ目の矩形 |
| プロファイル | – | キーキャップの形状規格 (DCS, DSA, SA 等)。本アプリでは保持しない |

## 電気・基板

| 用語 | コード上の名前 | 説明 |
|---|---|---|
| マトリクス | `matrix`, `MatrixAddress` | スイッチを行と列の格子として配線する方式。少ないピン数で多くのキーを読む |
| Row / Col | `row` / `col` | マトリクスの行番号・列番号。物理的な行・列と一致させる必要はない |
| ダイオード方向 | `diodeDirection`, `COL2ROW` / `ROW2COL` | 各スイッチに入れる直列ダイオードの向き。QMK の設定と一致させる必要がある |
| ゴースト (誤検出) | – | ダイオードが無い場合に、3 キー同時押しで押していないキーが押されたと誤認される現象。上記の「ゴースト表示」とは別の意味 |
| ネット | `netRowName` 等 | 電気的に繋がっている配線の集合。KiCad が扱う単位 |
| フットプリント | – | 基板上の部品の実装形状 (パッド・穴の配置) |
| シンボル | `lib_symbols`, `lib_id` | 回路図上の部品記号 |
| Reference | `SW1`, `D1` | 部品の識別子。回路図と基板で一致させる |
| プレート | – | スイッチを固定する板。本アプリでは出力対象外 (将来検討) |
| 分割キーボード | `split`, `SplitSide` | 左右が物理的に分かれたキーボード |

## ツールとファイル

| 用語 | 説明 |
|---|---|
| KLE | [Keyboard Layout Editor](http://www.keyboard-layout-editor.com/)。ブラウザ上のレイアウトエディタ。本アプリが代替を目指す対象 |
| Raw data | KLE のレイアウト表現 (JSON5 に近い記法の配列)。[formats/KLE.md](formats/KLE.md) |
| kbd.json | KLE のプロジェクト保存形式 (メタ情報 + Raw data) |
| QMK | 自作キーボードで広く使われるファームウェア |
| `info.json` | QMK がキーボードの物理レイアウトを記述するファイル |
| keymap | どのキーに何のキーコードを割り当てるかの定義。本アプリの対象外 |
| QMK Configurator | ブラウザ上で QMK のキーマップを作るツール。`info.json` を読む |
| VIA / Vial | キーマップをリアルタイムに書き換えるツール。キーボード定義 JSON を必要とする |
| KiCad | オープンソースの回路図・基板 CAD |
| S 式 | KiCad のファイル形式に使われる、括弧で入れ子を表す記法 |
| Ergogen | パラメータ記述からキー配置と基板外形を生成するツール |
| MKD | 旧アプリ (Modern Keyboard Layout Editor) の呼称。Next.js + Konva 版 |

## 本アプリの内部用語

| 用語 | 説明 |
|---|---|
| プロジェクト | 1 つのキーボードレイアウト全体 (`ProjectModel`) |
| 編集状態 | 選択・ズーム・パン・ツールなど、保存されない UI の状態 (`EditorState`) |
| ツール | Select / Add Key / Rotate / Pan のいずれか。現在の操作モード |
| コマンド | 履歴 1 段に対応する編集操作の単位 (`core/commands/`) |
| ゴールデンファイル | 期待する出力を固定したテスト用ファイル。[TESTING.md](TESTING.md#ゴールデンファイル方式) |
| ラウンドトリップ | 取り込み → 書き出し → 取り込みで情報が保たれるかの検証 |
| オービット回転 | 複数選択時に、選択範囲の中心を軸として全体を公転させる回転 |
| 正規化 | 全キーの囲み矩形の左上が原点になるよう平行移動すること (出力時に行う) |
