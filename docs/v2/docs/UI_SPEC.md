# UI 仕様

デザインツール (Figma / Sketch) に近い操作モデルを採用します。
「無限キャンバス + 明示的なツール + 右インスペクタ + コマンドパレット」の構成です。

旧アプリの UI (TopBar / 左プリセット / キャンバス / 右プロパティ) は
機能面では足りていましたが、以下の問題がありました。本仕様はそれを解消することを
目的にしています。

| 旧アプリの問題 | 本仕様での対応 |
|---|---|
| ツールの概念がなく、常に「選択」モード。キー追加はサイドバーのクリックのみ | ツールを明示 (Select / Add / Rotate / Pan) し、ショートカットで切り替え |
| 操作が TopBar・左・右に散っていて発見しづらい | コマンドパレット (`Cmd/Ctrl+K`) に全操作を集約 |
| ダークテーマ固定、色が直書き | デザイントークン化し、ライト / ダーク / システム追従 |
| 選択中の状態 (何個選択中か、座標) が分かりにくい | 下部ステータスバーに常時表示 |
| 整列・分布の機能がない | 複数選択インスペクタに整列・分布を追加 |
| ズーム操作がホイールのみ | ズーム率の直接入力、全体表示、選択にズーム |

## 画面構成

```
┌──────────────────────────────────────────────────────────────────────┐
│ ツールバー (高さ 44px)                                                │
│ [ロゴ] [プロジェクト名▾] │ [↶][↷] │ [ツール群] │ [Grid▾][Snap] │ [⊕100%⊖] │ [取込][書出▾] │
├────────────┬──────────────────────────────────────────┬──────────────┤
│ 左パネル    │                                          │ インスペクタ  │
│ (幅 240px) │            キャンバス                      │ (幅 280px)   │
│            │                                          │              │
│ ・キー追加  │        無限スクロール / ズーム              │ 選択内容に    │
│ ・プロジェ  │                                          │ 応じて切替    │
│   クト一覧  │                                          │              │
├────────────┴──────────────────────────────────────────┴──────────────┤
│ ステータスバー (高さ 28px)  選択 3 個 │ x 2.25 y 1.00 │ Matrix 5×14 │ 保存済 │
└──────────────────────────────────────────────────────────────────────┘
```

- 左右のパネルは折りたたみ可能 (`Cmd/Ctrl+\` で左、`Cmd/Ctrl+Alt+\` で右)。
- 幅 1024px 未満では左パネルを既定で折りたたみ、768px 未満ではインスペクタを
  下部シートに切り替えます。

## ツールバー

| 要素 | 挙動 |
|---|---|
| プロジェクト名 | クリックでインライン編集。`Enter` で確定、`Esc` で取り消し |
| プロジェクトメニュー (▾) | 新規 / 複製 / 名前を変更 / 削除 / プロジェクト一覧を開く |
| Undo / Redo | 履歴が無いときは無効表示。ツールチップに操作名を出す (例: 「キーの移動を取り消す」) |
| ツール群 | Select / Add Key / Rotate / Pan の 4 ボタン。現在のツールを強調 |
| Grid | スナップ間隔の選択 (1 / 0.5 / 0.25 / 0.125 / 0.05U) |
| Snap | スナップの有効・無効トグル |
| ズーム | `-` / 倍率表示 (クリックで直接入力) / `+`。倍率表示の右クリックで「全体表示」「100%」「選択にズーム」 |
| 取込 | ファイル選択。拡張子と内容から形式を自動判別 ([formats/README.md](formats/README.md#入力の判別)) |
| 書出 (▾) | プロジェクト JSON / KLE raw JSON / QMK info.json / QMK keymap 雛形 / KiCad zip / VIA 定義 / Ergogen YAML |

## ツール

| ツール | ショートカット | 挙動 |
|---|---|---|
| Select | `V` | クリックで選択、ドラッグで矩形選択、キーの上をドラッグで移動 |
| Add Key | `K` | クリックした位置にキーを置く。ドラッグで連続配置。`Esc` で Select に戻る |
| Rotate | `R` | ドラッグで選択中のキーを回転。`Shift` で 15° 刻み |
| Pan | `Space` (押している間) / `H` | ドラッグでキャンバスを移動 |

Select ツール中も、中ボタンドラッグと 2 本指ドラッグでパンできます
(ツールを切り替える必要はありません)。

## キャンバス

### 表示

- グリッド線は 1U ごとに細線、5U ごとに太線。`scale < 0.4` では 1U 線を省略。
- 原点 (0, 0) に十字の目印。
- キーは角丸矩形 + 内側の凸面。刻印は 12 スロットに配置。
- 選択中のキーは輪郭を強調し、選択範囲全体にバウンディングボックスと回転ハンドルを出す。
- マトリクス番号の重ね表示トグル (`Cmd/Ctrl+M`)。
- `decal` のキーは点線の輪郭で描き、スイッチを持たないことを示す。
- `ghost` のキーは半透明。

### 操作

| 操作 | 挙動 |
|---|---|
| クリック | 単一選択。空白クリックで選択解除 |
| `Shift` + クリック | 選択に追加 / 選択から除外 |
| ドラッグ (空白から) | 矩形選択 (交差選択)。`Alt` 併用で包含選択 |
| ドラッグ (キーの上から) | 選択中のキーすべてを移動。スナップ有効時はグリッドに吸着 |
| `Alt` + ドラッグ | 複製しながら移動 |
| ダブルクリック | そのキーの主刻印をキャンバス上で直接編集 |
| ホイール | カーソル位置を固定点にズーム |
| `Shift` + ホイール | 横スクロール |
| ピンチ (2 本指) | パンとズームを同時に |
| 回転ハンドルのドラッグ | 選択範囲の中心を軸に回転 (複数選択時はオービット) |

### キーの重なり

キー追加時に既存キーと重なる場合、グリッド幅単位で右方向にずらして空きを探します
(旧アプリと同じ挙動、最大 100 回試行)。見つからない場合はそのまま置き、
ステータスバーに「重なっています」と表示します。重なりは禁止しません
(意図的に重ねるレイアウトがあるため)。

## インスペクタ

選択状態によって 3 つの表示に切り替わります。

### 無選択 — プロジェクト設定

| セクション | 項目 |
|---|---|
| プロジェクト | 名前、作成日時、更新日時、キー数 |
| キーボード情報 | Keyboard Name / Manufacturer / Maintainer / URL |
| USB | VID / PID / Device Version |
| マトリクス | ダイオード方向 (COL2ROW / ROW2COL)、分割キーボードか |
| ツール | マトリクス自動割り当て (開始 Row / Col 指定、全キー対象)、マトリクス検証 |

キーボード情報と USB は QMK 出力に使われます (旧アプリではハードコードされていました)。

### 単一選択 — キープロパティ

| セクション | 項目 |
|---|---|
| 刻印 | 12 スロットを 4 行 3 列で配置した入力欄。上段 3 / 中段 3 / 下段 3 / 前面 3 |
| 形状 | 矩形 / ISO Enter / ステップド / Big-Ass Enter。副矩形を持つ形状では副矩形の x2 y2 w2 h2 も編集可 |
| 座標 | X / Y (U) |
| 寸法 | W / H (U) |
| 回転 | 角度 (°)、回転中心 (幾何中心 / 座標指定の切替 + X / Y) |
| マトリクス | Row / Col、未割り当てにするボタン |
| フラグ | デカール / ホーミング / ゴースト |
| 色 | キーキャップ色 / 刻印色 (未指定はテーマ既定) |
| 操作 | 複製 / 削除 |

- 数値入力はドラッグでの増減に対応 (ラベル部分を左右ドラッグ)。
- 回転中心の「座標指定」は旧アプリで存在しなかった編集手段です
  (`rotationCenter` はフィールドだけあって UI が無く、常に `{0,0}` でした)。

### 複数選択

| セクション | 項目 |
|---|---|
| 概要 | 「N 個のキーを選択中」、選択範囲の寸法 |
| 一括編集 | W / H / 回転角 / 形状 / マトリクス Row / 色。値が揃っていない項目は「—」を表示し、入力すると全体に適用 |
| 整列 | 左 / 水平中央 / 右 / 上 / 垂直中央 / 下 |
| 分布 | 水平方向に等間隔 / 垂直方向に等間隔 |
| マトリクス | 自動割り当て (開始 Row / Col 指定、選択キーのみ) |
| 操作 | 複製 / 削除 |

整列・分布は旧アプリに無かった機能です。

## 左パネル

### キー追加 (プリセット)

クリックでキャンバス中央に追加、ドラッグ＆ドロップで任意の位置に追加。

| プリセット |
|---|
| 1U / 1.25U / 1.5U / 1.75U / 2U / 2.25U / 2.75U |
| 6.25U Space / 7U Space |
| ISO Enter / Big-Ass Enter / ステップド 1.75U |
| 縦 2U (テンキーの `+` 等) |

一括追加: 個数を指定してまとめて追加 (X 方向に隣接配置)。旧アプリの
TopBar の Count フィールドに相当する機能を、ここに移します。

### プロジェクト一覧

保存済みプロジェクトの一覧。現在のプロジェクトを先頭に固定表示し、
更新日時の降順で並べます。各項目から読み込み / 複製 / 削除。

## コマンドパレット (`Cmd/Ctrl+K`)

すべての操作をここから実行できます。ショートカットを覚えていなくても
名前で辿れるようにするのが目的です。

- 曖昧一致で検索。日本語と英語の両方で引けるようにする (例: 「せいれつ」「align」)。
- 各項目にショートカットを併記し、学習を促す。
- 最近使った操作を上位に出す。

## キーボードショートカット

旧アプリのショートカットはすべて引き継ぎます。

### 継承 (旧アプリと同じ)

| キー | 操作 |
|---|---|
| `Cmd/Ctrl+Z` | 取り消し |
| `Cmd/Ctrl+Shift+Z` / `Ctrl+Y` | やり直し |
| `Delete` / `Backspace` | 選択中のキーを削除 |
| `Cmd/Ctrl+C` / `Cmd/Ctrl+V` | コピー / 貼り付け |
| `↑` `↓` `←` `→` | 選択中のキーをグリッド幅だけ移動 |
| `Shift` + 矢印 | 1U 単位で移動 |
| `Tab` / `Shift+Tab` | 次 / 前のキーを選択 (Y → X の順に巡回) |

### 追加

| キー | 操作 |
|---|---|
| `Cmd/Ctrl+K` | コマンドパレット |
| `V` / `K` / `R` / `H` | ツール切り替え |
| `Space` (押下中) | 一時的にパン |
| `Cmd/Ctrl+A` | すべて選択 |
| `Esc` | 選択解除 / ツールを Select に戻す / ダイアログを閉じる |
| `Cmd/Ctrl+D` | 複製 |
| `Cmd/Ctrl+S` | プロジェクトを保存 (自動保存とは別に明示保存) |
| `Cmd/Ctrl+G` | スナップの有効・無効 |
| `Cmd/Ctrl+M` | マトリクス番号の表示切り替え |
| `Cmd/Ctrl+0` | ズーム 100% |
| `Shift+1` | 全体を表示 |
| `Shift+2` | 選択にズーム |
| `Alt` + ドラッグ | 複製しながら移動 |
| `?` | ショートカット一覧を表示 |

入力欄にフォーカスがあるときは、ツール切り替えなどの単独キーのショートカットを
無効にします (旧アプリと同じ)。ただし `Esc` と `Cmd/Ctrl` 併用のものは有効です。

## アクセシビリティ

- すべての操作をキーボードだけで完了できること。キャンバス上のキーは
  `Tab` で巡回でき、矢印キーで移動、`Enter` で刻印編集に入れます。
- フォーカスリングを消さない。`:focus-visible` で明示する。
- 文字と背景のコントラスト比は 4.5:1 以上 (上記トークンはこれを満たす)。
- 色だけで状態を伝えない。選択は輪郭の太さ、`decal` は点線、
  エラーはアイコンと文言を併用する。
- `prefers-reduced-motion: reduce` のときはアニメーションを無効にする。
- アイコンのみのボタンには `aria-label` を付ける。
- ダイアログは `role="dialog"` + フォーカストラップ + `Esc` で閉じる。

## エラーとフィードバック

- 破壊的操作 (プロジェクト削除、インポートによる置き換え) は確認ダイアログを出す。
- インポート失敗時は `alert` を使わず、画面内のトーストに理由を出す
  (「KLE raw JSON として解釈できませんでした: 3 行目の `r` の値が不正です」のように、
  どこが悪いかまで書く)。旧アプリは `alert('Failed to parse JSON')` のみでした。
- エクスポート時に不足情報があれば事前に警告する
  (例: マトリクス未割り当てのキーがある状態での KiCad 出力)。
- 自動保存の状態 (保存中 / 保存済み / 失敗) をステータスバーに出す。
