# Ergogen

[Ergogen](https://github.com/ergogen/ergogen) は「キー配置の記述 (YAML) から
基板の外形とフットプリント配置を生成する」ツールです。出力のみに対応します。

## 位置付け

Ergogen は本来、**行列の規則性をパラメータで記述する**ことに強みがあるツールです
(「この列を 3mm 下げる」「この行を 15° 傾ける」といった記述)。
本アプリが持っているのは展開後の絶対座標なので、出力できるのは
**各キーを個別に絶対座標で置いた、規則性のない YAML** になります。

そのため、この出力は以下の用途に向いています。

- Ergogen で基板外形とフットプリント配置を作る出発点にする
- 本アプリで作った配置を Ergogen ベースのワークフローに持ち込む

逆に、Ergogen の記述を本アプリに取り込む (入力) 対応は行いません。
パラメータ表現を絶対座標に展開してしまうと Ergogen の利点が失われ、
往復させる意味がないためです。

## 出力

`<name>.yaml` を 1 ファイル出力します。

```yaml
# 本アプリが生成した Ergogen 設定です。
# points.zones の各キーは絶対座標で配置されています。
units:
  kx: 19.05
  ky: 19.05

points:
  zones:
    matrix:
      anchor:
        shift: [0, 0]
      columns:
        col_0:
          rows:
            row_0:
              # 刻印: Esc / matrix: 0,0
              shift: [0, 0]
              rotate: 0
        col_1:
          rows:
            row_0:
              # 刻印: 1 / matrix: 0,1
              shift: [19.05, 0]
              rotate: 0

outlines:
  # 基板外形は生成していません。Ergogen 側で定義してください。
  keys:
    - what: rectangle
      where: true
      size: [18, 18]
```

### 座標の対応

| Ergogen | 本アプリ |
|---|---|
| `shift: [x, y]` | `[position.x * 19.05, -position.y * 19.05]` |
| `rotate` | `-rotation.angle` |

**Y 軸と回転の符号が反転します。** Ergogen は Y 上方向が正・反時計回りが正、
本アプリは Y 下方向が正・時計回りが正です。ここを間違えると上下が反転した
基板ができるので、テストで必ず確認します。

### 命名

- ゾーン名は `matrix` 固定。
- 列名は `col_<col>`、行名は `row_<row>` (マトリクスの番号を使う)。
- マトリクスが未割り当てのキーは、`col_x<連番>` / `row_y<連番>` として
  物理順で並べ、警告を出します (Ergogen 出力はマトリクスを必須としません)。

### 出力しないもの

- `outlines` の実際の外形 (プレースホルダのみ)
- `pcbs` (フットプリント割り当て・ネット)
- `cases`

これらは Ergogen 側で書く前提です。生成した YAML の先頭コメントに明記します。

## テスト

`tests/fixtures/ergogen/` にゴールデンファイルを置きます。

| フィクスチャ | 検証内容 |
|---|---|
| `4x4-macropad` | 基本の `shift` の算出 |
| `rotated-thumb` | Y 軸と回転の符号反転 |
| `no-matrix` | マトリクス未割り当て時の命名と警告 |

YAML は文字列として比較します (キーの順序が意味を持つため)。
`js-yaml` などのライブラリは使わず、決まった形の文字列を組み立てます
(出力する構造が固定なので、依存を増やす必要がありません)。
